# 2026-08-25 특수 권한과 셸 환경

출처: ktcloud-infra-강의노트1.docx의 8/25 기록. 명령은 계정·디렉터리가 준비된 실습 환경에서 개별 사용한다.

## 특수 권한

```bash
ls -l /usr/bin/passwd
ls -lL /usr/bin/locate
ls -ld /tmp
```

| 권한 | 숫자 | 의미 |
|---|---|---|
| SetUID | 4000 | 실행 중 유효 UID를 실행 파일 소유자로 설정 |
| SetGID | 2000 | 실행 파일의 유효 GID 설정 또는 공유 디렉터리의 그룹 상속 |
| Sticky bit | 1000 | 공용 디렉터리의 삭제·이름 변경 제한 |

Sticky bit는 파일 소유자뿐 아니라 디렉터리 소유자와 특권 사용자 등도 삭제할 수 있으므로 원문의 '소유자만'은 축약 설명으로 이해한다. 파일 내용 수정은 별도 파일 권한에 달려 있다.

## 그룹 공유 폴더

```bash
# root
usermod -aG wheel user1
id user1
# 공유 디렉터리 소유자 또는 root
chmod 1777 share
chgrp wheel share
chmod 3777 share
chmod 3770 share
ls -ld share
```

단계별 권한 비교 기록이다. 최종 3770은 SetGID+Sticky, 소유자·그룹 rwx, 기타 사용자 권한 없음이다. 공유 폴더에서 새 파일의 그룹이 wheel로 상속되는 결과를 확인했다. 기존 로그인 세션의 그룹 정보는 새 로그인 등이 필요할 수 있다.

## PATH와 프롬프트

```bash
mkdir bin
mv hello.sh bin
echo "$PATH"
which hello.sh
export PS1='\n\u@\h \w]\n\$ '
history
```

PATH는 명령 검색 경로다. 원문은 `PATH=$PATH:.`로 현재 폴더를 추가하는 실험도 포함하지만, 복습 시 현재 폴더 스크립트는 `./hello.sh`로 명시하는 편이 분명하다. PS1의 `\u`, `\h`, `\w`는 사용자·호스트·현재 경로를 표시한다.

```bash
name=student
echo "$name"
date +%H:%M
echo "The time is now $(date +%H:%M)."
```
