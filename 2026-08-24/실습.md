# 2026-08-24 파일과 링크

출처: ktcloud-infra-강의노트1.docx의 8/24 기록. 원문은 파일·디렉터리 관리 제목과 링크 비교 중심이다.

| 구분 | 하드 링크 | 심볼릭 링크 |
|---|---|---|
| 연결 방식 | 동일 inode 참조 | 다른 경로를 가리키는 별도 파일 |
| 원본 이름 삭제 | 다른 링크가 남으면 데이터 접근 가능 | 대상 경로가 없어지면 깨진 링크 |
| 파일 시스템 경계 | 넘을 수 없음 | 넘을 수 있음 |
| 디렉터리 연결 | 일반적으로 허용되지 않음 | 가능 |

개념 이해를 위한 보충 예시이며 원문에 실행 결과가 있는 명령은 아니다:

```bash
touch original.txt
ln original.txt hard.txt
ln -s original.txt symbolic.txt
ls -li original.txt hard.txt symbolic.txt
```

`ls -i`로 inode 번호를 비교할 수 있다. 하드 링크는 같은 파일의 또 다른 이름이며, 심볼릭 링크는 대상 경로를 저장한다.
