## Nginx 컨테이너

```bash
docker run -d -p 8080:80 nginx
docker ps
curl http://localhost:8080
```

컨테이너 ID가 반환됐으며 브라우저에서도 localhost:8080을 확인하는 흐름이다. `-d`는 백그라운드, `-p 8080:80`은 호스트 8080 포트를 컨테이너 80에 연결한다.

## 확장 glob

다음은 별도 실습 디렉터리에서 비교하는 예시다. `shopt` 줄은 확장 glob 사용 조건을 명확히 하기 위한 보충이다.

```bash
mkdir -p ~/lab/test
cd ~/lab/test
touch bl black blacklist blish blist block blue bla blackist
shopt -s extglob
ls bl*(ack|ish|ist|ock)
ls bl?(ack|ish|ist|ock)
ls bl+(ack|ish|ist|ock)
ls bl@(ack|ish|ist|ock)
ls bl!(ack|ish|ist|ock)
```

`*()` 0회 이상, `?()` 0~1회, `+()` 1회 이상, `@()` 하나의 패턴, `!()` 해당 패턴 제외를 비교한다. 파일 이름 확장이며 grep 정규식과는 다르다.

## sed로 설정 내용 변환

```bash
# 먼저 변경 결과만 출력
sed '/[[:space:]]swap[[:space:]]/s/^/#/' /etc/fstab
```

원문의 `sed -i '/swap/s/^/#/' /etc/fstab`는 swap 문자열이 있는 행 앞에 #을 붙여 파일 자체를 수정한다. fstab 수정은 이후 자동 활성화 설정을 바꾸며 현재 실행 중인 swap을 즉시 끄지는 않는다. 현재 swap 해제는 9/7의 swapoff 실습과 연결된다.

Dockerfile 작성, /etc/profile 이해, EC2 User Data를 통한 자동화는 목표로 소개되었다. 완성된 Dockerfile이나 EC2 배포 결과는 이 문서에서 확인되지 않는다.
