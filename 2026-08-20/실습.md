# 2026-08-20 시스템과 네트워크 기초

출처: ktcloud-infra-강의노트1.docx의 8/20 기록. VMware 설치 과정은 제외했다. 아래는 복습용 명령이며 일괄 실행 스크립트가 아니다. IP는 당시 예시로, 현재 환경과 다를 수 있다.

## 디스크와 현재 위치

```bash
lsblk
pwd
```

`lsblk`는 디스크·파티션·논리 볼륨과 마운트 위치를 보여준다. 기록에는 100GB 디스크 아래 /boot와 LVM의 /, swap, /home이 표시됐다. `pwd` 결과는 `/home/student`였다.

## 연결과 DNS

```bash
ping google.com
cat /etc/resolv.conf
ip addr
ip r
ss -np | more
```

- ping은 2개 전송·2개 수신, 손실 0%였다.
- DNS는 `192.168.120.2`였다. resolv.conf는 NetworkManager가 생성한 파일로 표시된다.
- 인터페이스 ens160의 당시 IPv4는 `192.168.120.130/24`였다.
- 기본 경로는 `192.168.120.2` 게이트웨이를 사용했다.
- `ss`는 소켓 상태를 확인하는 도구다.

Windows 비교 명령:

```powershell
ipconfig
route PRINT
netstat
```

IP 설정, 라우팅 테이블, 연결 상태를 각각 확인한다.
