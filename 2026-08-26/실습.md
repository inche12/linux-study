```vim

:r hello.sh
:r !date
```

현재 파일 다시 읽기(미저장 변경 폐기), 파일 내용 삽입, 명령 출력 삽입이다. 원문 .vimrc 설정:


## grep과 정규식

```bash
grep -E -v '^[[:space:]]*#|^$' /etc/profile
grep '^[[:space:]]\+#' /etc/profile
grep -E '^[[:space:]]+#' /etc/profile
```

첫 명령은 주석 행과 완전히 빈 행을 제외한다. `-v`는 불일치 행, `-E`는 확장 정규식이다. 공백만 있는 행까지 모두 제거하는 식은 아니다. /etc/profile의 PATH 초기화와 로그인 셸 환경도 살펴봤다.

## find 조건과 후속 작업

```bash
find /etc -name passwd 2>/dev/null
find ~ -mtime 1 -ls
find ~ -mtime +1 -ls
find ~ -mtime -1 -ls
find / -size +1000000c 2>/dev/null
find / -user student -type d 2>/dev/null
find / -perm -4000 -ls 2>/dev/null
find / -perm -2000 -ls 2>/dev/null
mkdir -p /tmp/bk
find . -name 'hello*' -ok cp {} /tmp/bk \;
find . -name 'hello*' -exec cp -r {} /tmp/bk \;
```

이름·수정 시각·크기·소유자·타입·권한 조건으로 검색한다. `-mtime`은 24시간 단위이며 단순 달력 날짜가 아니다. `-ok`는 작업마다 확인하고 `-exec`는 바로 실행한다. `2>/dev/null`은 오류 출력을 버린다.

## 좀비 프로세스 실험

`sleep 1000 &`, `ps`, `ps -l`, `watch ps -l -t pts/5`로 관찰했다. 부모 셸을 STOP한 뒤 자식을 종료하면 종료 상태가 회수되지 않아 좀비가 남고, 부모를 CONT하면 회수되는 과정을 확인했다. 원문 PID 11901은 당시 값이므로 재사용하지 않는다. `pkill sleep`도 같은 이름의 다른 프로세스에 영향을 줄 수 있다.

## 저장소와 Docker 설치

```bash
dnf repolist
dnf search docker
dnf install docker-ce
systemctl enable --now docker
systemctl status docker
```

원문은 `/etc/yum.repos.d/*.repo` 작성, epel-release 설치, `dnf config-manager --add-repo` 방식으로 저장소를 등록하는 방법을 다룬다. config-manager 문법은 설치된 DNF 버전에 맞춰 확인한다. Docker 저장소 주소는 https://download.docker.com/linux/centos/docker-ce.repo 이다.

Docker 시작 오류에 대해 kernel-modules-extra 설치 → Docker 재시작 → 업데이트·재부팅 후 상태 확인을 시도한 기록이다. 모든 Docker 시작 오류에 동일하게 적용되는 처방은 아니다.
