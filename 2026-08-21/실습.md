# 2026-08-21 계정 전환과 SSH

출처: ktcloud-infra-강의노트1.docx의 8/21 기록. 명령은 복습용이며 비밀번호는 제외했다.

## 사용자 전환

```bash
id
su root
pwd
exit
su - root
pwd
exit
```

`id`는 UID·GID·소속 그룹을 확인한다. `su root`와 `su - root`는 전환 후 환경이 다르며, 후자는 로그인 환경을 구성하고 대상 사용자의 홈으로 이동한다. 문서 화면에서는 단순 su 후 기존 `/home/student` 위치가 유지되는 모습을 비교했다.

## SSH 서버와 원격 접속

```bash
systemctl status sshd
```

기록에서 sshd는 active(running)이며 IPv4·IPv6의 22번 포트에서 대기했다. MobaXterm의 SSH 세션에 당시 서버 주소 `192.168.120.130`, 사용자 student, 포트 22를 입력해 원격 접속했다. Xshell은 선택 도구로 소개됐다.

동일한 목적의 터미널 명령 예시:

```bash
ssh student@192.168.120.130
```

온프레미스 데이터센터, Azure 데이터센터, CNCF 생태계 링크도 소개되어 있으나 별도 구축 결과는 기록되어 있지 않다.
